# Enneagram Audience Reach

A Claude Code skill that analyzes writing to discover which audiences truly
hear the message, and suggests targeted revisions to expand reach.

## What it does

Most persuasion fails because ideas are framed for one motivational lens
while other audiences ask different questions. This skill scores a text's
current appeal across all nine Enneagram types (0-100% coverage per type),
identifies gap severity, and suggests revisions that shift which legitimate
dimensions of the argument receive emphasis — not tone, not buzzwords.

Every suggestion carries a confidence tier (high / moderate / exploratory)
and passes through an integrity check: revisions may never remove valid
counterarguments, exploit fear or FOMO, weaponize belonging to suppress
accountability questions, or fabricate evidence to fit a personality frame.
It also flags performativity gaps (values without implementation) and
missing hope/emergence framing in crisis communication.

## When it triggers

Use it to audit a sermon, speech, proposal, mission statement, marketing
copy, or any communication meant to land across diverse audiences — or when
asked "would this resonate with X type of person" or to check for
manipulation risk in persuasive writing.

## Files

- [`SKILL.md`](./SKILL.md) — the skill definition: the nine motivational
  frames, coverage scoring, red-flag detection, revision confidence tiers,
  and integrity gates.

## Note

The Enneagram is not empirically established as a personality taxonomy.
The skill treats type as a rhetorical hypothesis about motivational
salience, not scientific fact, and never weakens evidence to achieve
"type fit."
