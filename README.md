# Claude-Skills

## Skills

- [`skills/invoice`](./skills/invoice) — Invoice Builder. Generates
  client invoices for independent contract work, anchored to signed agreements.
- [`skills/premortem`](./skills/premortem) — Premortem. Conducts rigorous
  prospective-hindsight premortems for projects, strategies, launches,
  decisions, and AI workflows.
- [`skills/personality-type`](./skills/personality-type) — Enneagram
  Audience Reach. Analyzes writing to discover which audiences it currently
  resonates with, then suggests revisions to expand reach across the nine
  Enneagram motivational types without compromising integrity.

## Applications

- [`groundwork`](./groundwork) — **Groundwork.** An interview-first grant
  narrative tool for nonprofit leaders. Adapts its interview to whatever
  funder application you give it, records only what the leader actually said,
  routes everything uncertain back to them, and assembles a draft from
  approved facts — with a code-enforced guarantee that no number reaches the
  page unless it traces to something the leader stated.
